# Datalith - From pixel to knowledge

A local-first Vault where notes, links, and tasks sharpen into a monolith that lasts.

Datalith is a desktop application for building a private personal encyclopedia from files you own. Write notes, manage tasks, connect ideas, and search inside. Available on macOS, Windows, and Linux.

## Features

- Local-first Vaults backed by ordinary files on disk
- Markdown editing with live preview, YAML frontmatter, and Wiki Links
- Relevance-ranked search across file names and content
- A todo.txt editor with priorities, projects, contexts, filtering, sorting, completion, and subtasks
- Graph Views that visualize Wiki Links between notes
- Light and dark themes with additional bundled themes
- Private by default: your Vault files stay on your machine
