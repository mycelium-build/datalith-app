# Files

| Shortcut | Action |
| --- | --- |
| `⌘N` | New file |
| `⌘⇧N` | New folder |
| `F2` | Rename |
| `⌘⌫` | Delete |
| `⌘D` | Duplicate |
| `⌘⇧E` | Open in Explorer / Finder |
| `⌘L` | Copy path |

# Sidebar

| Shortcut | Action |
| --- | --- |
| `⌘0` | Focus sidebar |
| `↩` | Expand/collapse folder, or open file |
| `⌘↩` | Open file in a new tab |
| `↑` / `↓` | Move through the file tree |

# Navigate

| Shortcut | Action |
| --- | --- |
| `⌘P` | Quick switcher (open files) |
| `⌘⇧F` | Search files |
| `⌘0` | Focus sidebar |
| `⌘[` / `⌘]` | Go back / forward |
| `⌘↩` | Open link under cursor |

# Tabs

| Shortcut | Action |
| --- | --- |
| `⌘T` | New tab |
| `⌘W` | Close tab |
| `⌘1`-`⌘9` | Select tab 1-9 |
| `⌘E` | Toggle edit / view mode |

# Appearance

| Shortcut | Action |
| --- | --- |
| `⌘⇧D` | Toggle light / dark theme |

For the full set of options, see [[Settings]]. See [[Basics]] if you are new to the app.
