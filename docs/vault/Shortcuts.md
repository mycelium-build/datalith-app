# Files

| Shortcut | Action |
| --- | --- |
| `⌘N` | New note |
| `⌘⇧N` | New folder |
| `F2` | Rename |
| `⌘⌫` | Delete |
| `⌘D` | Duplicate |
| `⌘⇧E` | Open in your explorer |
| `⌘L` | Copy path |

# Sidebar

| Shortcut | Action |
| --- | --- |
| `⌘0` | Focus sidebar |
| `↩` | Expand/collapse folder, or open file |
| `⌘↩` | Open file in a new tab |
| `↑` / `↓` | Select file |

# Navigation

| Shortcut | Action |
| --- | --- |
| `⌘P` | Quick switcher |
| `⌘0` | Focus sidebar |
| `⌘[` / `⌘]` | Go back / forward |
| `⌘↩` | Open link at cursor |
| `⌘Q` | Quit Datalith |

# Tabs

| Shortcut | Action |
| --- | --- |
| `⌘T` | New tab |
| `⌘W` | Close tab |
| `⌘1`-`⌘8` | Select tab |
| `⌘9` | Select last tab |
| `⌘E` | Toggle edit/view mode |

# View

| Shortcut | Action |
| --- | --- |
| `⌘⇧F` | Search files |
| `⌘E` | Toggle edit / view |
| `⌘⇧D` | Toggle between light and dark theme |
| `⌘,` | Open settings |
