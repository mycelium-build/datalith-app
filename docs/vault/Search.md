Datalith keeps a search index of your Vault's file names and contents, so you can find files even when you don't remember where they are.

# Find files by name or content

- Press **⌘⇧F** (or click the search icon in the sidebar header) to open the search palette.
- Type at least three characters. Matches appear as you type; **↑/↓** moves through results and **Enter** opens the selected file.

# Quick switcher

- Press **⌘P** (or the grid icon in the sidebar header) to switch between currently open files.
- The switcher lists your open tabs, so you can jump between them without reaching for the mouse.

# What is searchable

Search covers files whose registered file type enables text search (like Markdown and todo.txt). The index is derived from your files and updates as you edit, including changes made outside Datalith.
